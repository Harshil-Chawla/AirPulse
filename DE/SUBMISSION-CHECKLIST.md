# Final submission checklist

- [x] PostgreSQL selection and justification
- [x] Attributes, keys, enums, cardinality and viewable ER diagram
- [x] Functional dependencies and 1NF/2NF/3NF discussion
- [x] Exact implemented Prisma schema and SQL migration
- [x] Sample records and isolated fixture
- [x] 12 meaningful query operations and explanations
- [ ] Run query runner and include actual execution output
- [ ] Capture real application/database before-and-after persistence evidence
- [ ] Resolve or disclose missing application UPDATE/DELETE functionality
- [x] Integrity, indexing and implementation limitations documented
- [x] Video script and recording sequence
- [ ] Record video and set submission link access as instructed
- [ ] Put DE at repository root and commit/push the resources
- [ ] Every team member reviews database design and SQL

The checkboxes distinguish prepared documentation from actual demonstration evidence. A pack with pending live evidence is not a claim that every mandatory requirement is fulfilled.
